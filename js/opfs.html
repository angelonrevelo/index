index — an index in the browser's own filesystem

profstopick ships a 2,505,813-byte JSON shard that occupies 95.6 % of the 5 MB localStorage quota, and its production instrumentation measured 109 of 267 real searches returning nothing — 40.8 % zero-result. This page replaces both: the same .idx the server and the CLI use, persisted to OPFS, queried with no network call at all after the first visit.

Nobody else occupies this tier, and not for lack of interest: Tantivy's WASM RFC has been open since 2019 and is read-only, LanceDB closed WASM as "not planned", Orama's Rust core has no wasm32 target, and Meilisearch and Elasticsearch are servers. See docs/research/landscape.md §7.5.
